# macOS Installation

This guide covers the current Apple Silicon workflow for 360-to-UE Previs.

## Requirements

- Apple Silicon Mac
- Homebrew
- FFmpeg / FFprobe
- Python 3.12
- COLMAP / PyCOLMAP
- 360 COLMAP rig pipeline
- Brush
- Unreal Engine
- Harmony Gaussian Splat plugin

## 1. Install Homebrew Dependencies

Install Homebrew if needed, then:

```bash
brew install ffmpeg
brew install colmap
Verify:
ffmpeg -version
colmap -h
python3 --version
2. Install the 360 COLMAP Pipeline
The current workflow is based on the 3GOVideo COLMAP 360 rig pipeline.
The default location expected by 360_TO_UE.command is:
~/Downloads/colmap-360-rig-pipeline
The directory should contain:
panorama_sfm_4_1_1.py
.venv/
Activate the Python environment:
cd ~/Downloads/colmap-360-rig-pipeline
source .venv/bin/activate
Verify PyCOLMAP:
python -c "import pycolmap; print(pycolmap.__version__)"
If your pipeline is stored somewhere else, set:
export PIPELINE="/your/custom/path"
3. Install Brush
Download the Apple Silicon build of Brush.
The executable used during development was:
/Applications/brush-app-aarch64-apple-darwin/brush_app
Verify it:
/Applications/brush-app-aarch64-apple-darwin/brush_app --help
If Brush is installed somewhere else:
export BRUSH="/your/path/to/brush_app"
4. Install 360-to-UE Previs
Clone this repository:
git clone https://github.com/ChansoulTao/360-to-ue-previs.git
cd 360-to-ue-previs
Make the launcher executable:
chmod +x 360_TO_UE.command
Run:
./360_TO_UE.command
You can also drag a compatible 360 video onto 360_TO_UE.command in Finder.
5. Input Format
The source should be a full equirectangular 360 video.
The script expects:
width = 2 × height
Examples:
7680 × 3840
5760 × 2880
A normal reframed 16:9 Insta360 export will not work.
6. Unreal Engine
The current tested workflow uses Unreal Engine 5.8 with the Harmony Gaussian Splat renderer.
The final PLY generated by this pipeline can then be imported into the Unreal previs project.
See:
docs/UNREAL_SETUP.md
